# 十段可复用提示词

根据 Eian 原文的十类提示词整理；不是逐字转载。方括号替换为真实项目材料。提示词不赋予工具、预算或多 agent 权限；模型、价格、接口必须另行核实。

## 1. 总导演启动

```text
你担任这支短片的总导演，我只和你沟通。先确认创意、片长、画幅、总预算、画风参考、音乐、字幕和对白。检查实际可用的生图工具、视频服务、ffmpeg/ffprobe 和脚本运行时；只检查密钥是否配置，绝不打印密钥。
你负责剧情、分镜、提示词、资产检查、制作调度和代码后期；已验证有生图能力的工具负责图片；已接入的视频服务负责动画；我确认故事、画风、费用和动态/声音。
建立独立项目目录，所有新版本另存，不覆盖或删除原件。
故事未确认不画图；画风未确认不画正式镜头；提交前审核图与提示词，审核通过后报价，我批准才提交。重拍先修改原因，不原样盲重试。
不充值、不买额度，欠费停相关生成，尽可能把已有片段粗剪。不要把抽帧当作看过完整动态，不要声称听过无法试听的声音。
```

## 2. 完善故事

```text
创意：[一句话/初步剧情]。片长：[秒]。用途和受众：[内容]。音乐：[无/曲目、授权情况、时长、BPM]。参考：[路径或链接]。
先和我讨论完整故事，不清楚就问，等我确认再进入分镜。优先考虑片段式，连续叙事要明确一致性风险。
先写一句话主题，再写逐镜头故事。每个转折追问为什么、物品从哪来、空间够不够、现实是否成立。最抓人的画面尽早出现并标秒数。
每个包袱写问题→解决→旁人反应，反应错开。优先选择模型易实现的拍法，减少交叉遮挡、小物件、镜面、文字、左右不对称、多动作和过多配角。
配乐时提出转折、副歌、重拍的对应方案，不声称未经分析的音乐已精确对拍。
```

## 3. 故事冷读审核

```text
材料：[仅定稿故事的路径及版本]。
你第一次看到这支短片，只读挑错，不改文件。只按镜头顺序先复述你看懂的故事，再逐个检查因果、物品来源、空间、主题、开头钩子、反应先后和 AI 实现风险。
每条写镜头编号、问题、证据、建议；没把握写可能。不要推测作者想表达但没写出的内容。最后写通过/不通过/材料不足，列出硬伤和未验证项。
```

## 4. 分镜与配色

```text
材料：[已批准故事]。目标：[画幅、片长、帧率]。配色偏好：[内容/给我方案]。
写分镜表，每镜一行：片中时间、成片时长、生成时长、景别、机位、运镜及动机、画面左右、动作顺序、表情、运动主体、转场、色彩、声音和风险。
生成时长符合当前服务档位并预留剪辑余量，费用按生成时长计算。改变角度与景别；不要为了运动而运动，保留必要静止。每镜说明什么在变、为何让观众看它。
逐场设计色板，画目标画幅的色块草图，标出约 38%/62% 参考线；制作总览与灰度对照检查主体分离。黄金比例只作建议，不机械套用。
有参考片时只有在实际访问解码后才分析，不声称看过无法读取的文件。提交给我确认后再画正式镜头。
```

## 5. 首尾帧检查

```text
材料：[首帧、尾帧、设定图、分镜、色板的实际路径及版本]。
实际读取并放大每张图，另做手机大小预览及首尾叠图。检查动作需要的物件是否已在首帧，旁人反应是否可见，群体姿势是否机械一致，运动路径和落点是否留空，风向光向是否一致，远处主体能否辨认，是否多余物体/肢体/细线。
检查机位、尺寸、道具尺度和背景变化是否符合运镜意图。每条写哪张图、哪个位置、证据、建议；用户同意才改。不能看图时明确说明，不伪造通过。
局部修改需要比对整图副作用，合回局部前验证边界、光色与透视。保留原件。
```

## 6. 七段式视频提示词

```text
【画风】[线条/材质/光照等一句话风格]，与已批准首尾帧和设定一致。
【镜头】整段 [X] 秒，[景别]，[机位]，[运镜及动机]；单镜内不切镜。
【构图与配色】[人物、物件的画面位置，主辅色、光向、背景；与帧图对应]。
【人物】[每个角色 ID、长相、服饰、固定特征、道具及数量]。
【逐秒】[首段可短暂停留]；[逐段写谁先谁后、动作原因、手的位置、移动路径与画面左右，每镜一两个主要动作]；[结束状态与尾帧一致，按时长安排停留]。
【声音】[有可见原因的音效；是否对白/音乐，按需求填写]。
【约束】[允许的人物、物品、数量、固定特征和状态]，一镜到底；画面内不生成字幕水印，用户需要的字幕在后期另加。
```

时间分段是模型指导，不是严格时序保证。提交前检查七段互不矛盾；不要求「全程无光线变化」同时又要求「光线变化推进剧情」。

## 7. 付费提交前审核

```text
你是只读审核，这个镜头即将花钱生成。
材料：[提示词、首帧、尾帧、设定、分镜、色板；各路径与版本]。
逐项实际核对：提示词每句话与图的左右、位置、颜色、人数、数量、服装、表情是否相符；两图机位、尺度、背景是否合理；是否与设定和前后镜头一致；动作是否现实、有因果、手的位置是否明确；是否有同步动作、凭空出现、拟人化、方向或歧义风险。
先列问题与证据，再写通过/不通过/材料不足。不通过必须逐项列修正要求。审核通过只代表内容可提交，不代表批准费用。
```

## 8. 代码后期

```text
输入：[每镜已选版本、剪辑表、原音乐、字幕和授权情况]。交付规格：[尺寸、帧率、编码、音轨、时长]。
先用 ffprobe 核实所有素材的实际属性和色彩元数据，再制定处理链。按分镜做转场、分段调色、节奏和字幕；保护肤色与强调色，未经批准不加颗粒柔光暗角。
色彩矩阵与范围按实际素材确定，不统一强制 BT.601；交付 BT.709 时真正转换并正确标记。中间文件尽量无损，注意磁盘空间。
720p→1080p 可用 lanczos 加轻微锐化，但不称为原生细节。不默认整段插帧。音乐节拍从原曲测，切点前后各查至少 3 帧。
完整解码验证成片。不能实际判断的动态/声音列待人工验收，不宣称已看/听过。
```

## 9. 全片冷读复核

```text
成片：[文件]。你第一次看，不提供制作方结论。先核实解码可用，再逐镜多点取全分辨率帧，切点前后各取至少 3 帧。
先复述看懂的故事，再列看不懂之处；检查重复动作、道具数量、穿帮、突跳、颜色变化、脸变形、文字与字幕。每条写时间、帧号、证据，区分硬伤与小问题。
明确说明哪些是抽帧证据、哪些是完整动态观看证据；无能力试听不判断音效正确，交给人工。最终给技术检查、视觉抽帧、动态和声音各自的验收状态。
```

## 10. 可选四线程

```text
在我明确授权多 agent 且环境支持时采用四角色。需求来源：[要求文件]，总预算：[币种、金额]，允许代决范围：[明确列表]，单次上限：[金额]。
主做负责制作；审核只读挑错，每一步核查，提交前明确通过；监督把我说过的话列成要求清单并逐步核对；代理只按我明确授权的偏好和金额范围代决，没有覆盖的决定必须问我。
每步主做→审核→监督。有分歧提出建议或交给获授权的代理，不能绕开安全限制或费用授权。记录每个决定、任务、失败和费用；生成前报价，欠费即停，不充值不买额度。
没有独立 agent 时明确说明限制，不冒充四线程，不伪造独立审核。可以请求人工审核或继续不花钱的准备工作。
```
