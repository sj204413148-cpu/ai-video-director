# 审核门槛与错误库

每次审核记录：审核者/方式、材料路径与版本、逐条证据、硬伤、小问题、未验证项、结论。材料变更使受影响的旧结论失效，必须复审。未知不是通过。审核角色只读，不直接修改制作文件。

## 故事

- 冷读先复述看懂的故事，不能借助作者意图补全因果。
- 一句话主题明确；开头钩子有时间点。
- 每个转折的物品来源、空间可达性、动作动机成立。
- 「问题→解决→反应」能读懂，反应错开且像真人。
- 识别高风险镜头并给出更稳的替代拍法。
- 结论必须为通过、不通过，或因材料不足无法判断。

## 分镜与首尾帧

- 时长、节奏、生成档位、画幅相容，动作有足够时间。
- 动作要用的东西已在首帧，旁人反应能在同一镜头看到。
- 群像姿势不机械一致；道具数量明确。
- 落点、运动路径、头顶和出入画有空间。
- 风向、光向、颜色和天气一致，帽子/饰品等固定特征两帧都在。
- 缩到手机大小仍能辨认，放大检查多余肢体、细线、重复道具。
- 叠图检查机位、尺度、背景；运动所需变化应与意图一致，不强求所有像素不变。
- 当前工具确实读取过所述图片；没有视觉能力时不输出「已放大检查」。

## 提交前

- 提示词逐句对应图片中的左右、位置、人数、数量、衣服、颜色、表情。
- 首尾帧、设定、邻镜、色板一致；不存在未解释的突变。
- 动作因果、手的位置、画面路径、先后明确；主要动作不过载。
- 七段式完整，没有相互矛盾的肯定/否定描述。
- 使用当前服务支持的参数与图片输入方式。
- 文件版本一致，审核已通过，用户费用授权覆盖本次任务；预算含待结算费用。

## 常见错误 → 提示词/设计修正

| 错误 | 修正 |
| --- | --- |
| 群体同步动作 | 写谁先谁后和间隔，首帧姿势错开 |
| 应由风推动却由人动手 | 写因果和两手状态，避免含糊动词 |
| 云/月亮长出五官 | 描写真实形态和纹理，不写拟人化「卡通云」 |
| 人走反方向 | 使用画面左/右和可见地标 |
| 位置歧义 | 明确左上角哪扇窗口、哪个人物；保持其他位置状态明确 |
| 数量变化 | 写明确数量与颜色、物品 ID |
| 否定词无效 | 优先正面描述稳定状态，必要时减少易误解道具 |
| 凭空出现/瞬移 | 首帧放好道具，逐步写清移动路径 |
| 雨/帽子/纹身消失 | 首尾帧都画上，设定写死 |
| 一个镜头动作太多 | 拆镜或减为一两个主要动作 |
| 时间不精确 | 生成留余量，后期剪辑/轻微变速，不承诺逐秒严格执行 |
| 推近不足 | 首尾帧体现透视/尺度意图，必要时后期轻推 |
| 嘴自行运动 | 明确无对白，修复或重拍前先判断是否影响叙事 |
| 混进音乐 | 实际试听，不可用的原音轨弃用并重做音效 |
| 结尾突跳/首帧过锐 | 检查原片，修剪坏帧或短暂定帧；不能掩盖重要动作 |
| 越拍越暗/偏冷 | 按实际素材和参考帧匹配曝光、色彩，先验证转换矩阵 |

这些是常见风险，不保证任何具体模型必然有或没有这些问题。

## 成片

- 完整解码无错误，时长/尺寸/帧率/音轨与交付约定一致。
- 每镜抽取多点全分辨率帧，切点前后各至少 3 帧；记录时间与帧号。
- 先复述故事，再查道具数量、重复动作、穿帮、突跳、脸变化、色偏、文字/字幕。
- 检查正常速率播放的动态、动作连贯、节奏和声音：必须由确实具备相应能力的工具或人工完成。
- 区分「抽帧检查通过」「技术验证通过」「人工动态/声音待验收」，不以其中一个代替全片通过。
